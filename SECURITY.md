# Security and privacy

PCA-SC-Bench is currently a public pre-release repository. We take accidental disclosure of credentials, private research artifacts, personal information, and restricted benchmark material seriously.

## Reporting an issue

Please report security or privacy concerns privately through the repository owner's GitHub profile or GitHub's private vulnerability-reporting feature when it is available. Do not open a public issue containing the sensitive material.

Include only the minimum information needed to identify the problem. If the report concerns an exposed secret, do not copy the secret into additional channels.

## Public disclosure

Please allow the maintainers time to investigate and remove or rotate affected material before discussing the issue publicly. Research questions, benchmark limitations, and ordinary documentation bugs may be reported through the standard issue tracker once it is enabled.
