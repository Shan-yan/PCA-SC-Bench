# Contributing

Thank you for your interest in PCA-SC-Bench. The project is currently in a pre-release phase, so contributions are limited to public-facing documentation and non-sensitive project infrastructure.

## Before opening a pull request

Please make sure your change:

- does not contain benchmark samples, images, annotations, prompts, model outputs, evaluation logs, result tables, figures, or manuscript text;
- does not contain API keys, access tokens, private endpoints, local absolute paths, or personal information;
- does not make unverified performance or safety claims; and
- keeps the English and Chinese documentation aligned when changing shared content.

For security or privacy issues, do not open a public issue. Follow [SECURITY.md](SECURITY.md) instead.

## Current contribution scope

Useful contributions at this stage include typo fixes, accessibility improvements, broken-link fixes, and suggestions that do not depend on access to private research artifacts. Code, data, and benchmark-content contributions will be considered after the public artifact release.

By submitting a contribution, you agree that it may be distributed under the repository's license.
